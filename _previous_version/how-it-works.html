Under the hood

How BrandGuard decides what to flag

A reviewer people trust has to be explainable. Every finding comes from an exact rule or from a model answer that passed a source check.

The pipeline

1. SegmentSplit the draft into sentences, numbers and claims.
2. Exact rulesTerms, absolutes, facts, claims register, accessibility, readability.
3. RetrievePick the brand rules and facts relevant to the draft.
4. JudgeClaude reads the draft against those rules only and returns structured findings.
5. VerifyKeep a finding only if its rule ID exists and its quote is in the draft.
6. DecideA person accepts, edits or disputes. Reviewers approve.

What each part is responsible for

CheckMethodWhy
Terminology, absolutes, readability, accessibilityExact rules in the browserDeterministic, instant and testable. A banned word is either there or not.
Facts and expiryNumber matching against the approved fact baseA wrong or outdated figure is a data question, not an opinion. Expired facts name their owner.
Claims registerPattern match, then evidence lookupA claim with evidence on file passes. Without it, it goes to a reviewer.
Tone and implied claimsClaude, then the source checkJudgement a keyword list cannot do. The check removes anything it cannot ground.

Human control and privacy

AI never acts alone

It proposes. It cannot edit a draft, publish, or approve. Every fix needs a click, and every dispute needs a written reason.

Role-based approval

Creators cannot approve their own work. Content with open high-severity findings cannot be approved. Any edit after approval starts a new version that needs review again.

Data stays small

Exact checks never leave the browser. The optional Claude check sends only the draft and the brand rule list. Brand data in this demo is fictional.

Technology

Front end

Plain HTML, CSS and JavaScript across six pages. No build step, so it opens anywhere.

State

Browser storage shared between pages: brand pack, drafts, versions, comments, audit trail and events.

AI

Claude through claude.ai, or through a small cloud function when hosted elsewhere. Used for the deep check and for rewording unclear rules.
